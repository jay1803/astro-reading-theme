# Validation guidance

Resolve applicable validation commands from package/build manifests, CI, and
maintained project instructions. Use checks that exercise the changed behavior
and satisfy the applicable delivery workflow and required CI gates.

Report which commands ran and their results. Distinguish a passing check from a
skipped, unavailable, or failed check. Do not invent command names or describe
an uploaded artifact as proof of runtime deployment.

Project-specific mandatory commands and their applicability can be recorded
here once verified from the repository. This module adds no fixed test suite.
